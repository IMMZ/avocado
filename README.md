# Avocado graphic engine
## Description
Avocado engine is an attempt to write a renderer on C++ using Vulkan.
Main keys are performance and ability to use in some demo game.
Written with:
- C++20
- Vulkan (GAPI)
- SDL (window management, keyboard handling)
- Catch3 (unit tests)

## Build
To build on Debian you should do the next steps:
- install package vulkan-tools;
- install package libsdl2-dev;
- install package libsdl2-image-dev;
- download and install VulkanSDK from LunarG website and setup VULKAN_SDK OS environment.
